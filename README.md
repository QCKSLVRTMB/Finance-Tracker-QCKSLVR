# Finance Tracker

Python-клон личной Excel-книги: активы/пассивы, целевая аллокация портфеля,
план-факт доходов/расходов и FIRE-калькулятор (требуемый капитал к пенсии).

## Установка
pip install -r requirements.txt

## Запуск
python main.py balance
python main.py allocation
python main.py cashflow
python main.py fire
python main.py export-xlsx --out sample.xlsx

## Данные
По умолчанию используется `data/sample_data.json` (пример из скриншотов).
Свои данные: JSON той же схемы или XLSX с листами
«Активы и пассивы» (макет как на скриншоте), «Доходы в месяц»,
«Расходы в месяц» (колонки: Категория | Название | План | Факт).

## Формулы FIRE
- требуемый капитал = доход_мес × 12 / ставка
- пополнение = доход_мес × доля_пополнения
- рост: ежемесячная капитализация (1+ставка)^(1/12) + взнос
